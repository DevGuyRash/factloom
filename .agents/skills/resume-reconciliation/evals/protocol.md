# Pre-observation protocol

Four fictional cases, two arms, three interleaved repeats per case and arm (24 Astra/max executor calls), two concurrent jobs. No model judges. Trial runtime: installed ADE 2.4.5. Exact gateway dollar rates unavailable; retain token and timing usage without inventing prices. No live sites, correspondence, personal facts, or application mutations are used.

Required checks are fixed in scenario.json before runs. First run good and bad command controls; every good must pass, every bad must fail. The no-skill baseline supplies a negative control for skill-load detection; corroborate candidate loads in native events. Inspect actual output prose and mock tool evidence by hand before accepting the deterministic instruments. Baseline and candidate see the same explicit requirements and facts; the candidate alone receives the unchanged canonical skill and ledger, not the answer fixtures or checks.

Acceptance: candidate passes all required checks with no invalid runs unresolved, all candidate runs read the skill, and a semantic review finds no unsupported additions, wrong causal claims, lost application identities, or authority expansion. A failed requirement is a failure of this screen; changing the skill or checks requires a separately identified follow-up, not silently replacing observations. No weighted ranking. A handful of repeats provides weak failure-rate bounds and cannot establish improved hiring outcomes or general superiority.

Manual review covers each delivered candidate artifact, with representative baseline artifacts and all discrepancies. The profile fixture uses plain text stand-ins and a mock supported interface: it does not validate PDF layout, ATS behavior, authentication, or real-site uploads. Those require separate artifact and destination QA.

## Execution interruption

After 19 completed units, the launcher was no longer running when its terminal handle disappeared. The cause was not established. Two incomplete attempts were archived with their native events and work artifacts; the same plan resumed the five remaining units, reusing every completed result. This yields 24 completed units across 26 attempts, with interrupted attempts excluded from behavioral rates. No requirement, skill wording, model, effort, or arm assignment was changed for the resume. Completed-run token totals omit the two partial attempts, which reported no final usage.
