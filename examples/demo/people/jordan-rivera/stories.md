# Stories for written answers

Each story uses only facts verified in `evidence.md`. `Competencies` are the tags `stories find <competency>` matches against.

### replacing-manual-reports

- Competencies: automation, process improvement, ownership
- Situation: Dispatch tracked on-time delivery in three spreadsheets that disagreed.
- Action: Built one Tableau dashboard on a SQL model of every shipment, and walked dispatch leads through it.
- Result: The spreadsheets were retired; the dashboard is the source for weekly reviews.

### cleaning-up-shared-data

- Competencies: data quality, collaboration, attention to detail
- Situation: Four clinics shared a scheduling system with duplicate patient records.
- Action: Wrote a repeatable SQL check and resolved each duplicate with the clinic that owned it.
- Result: 300+ duplicates resolved; the check runs monthly.
